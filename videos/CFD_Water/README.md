# CFD Water Simulation Videos

Upload your water-flow CFD videos here.

Supported formats:
- MP4
- WebM
- MOV
- M4V

Example:
`videos/CFD_Water/water-flow-pump.mp4`

Optional caption file:
`videos/CFD_Water/water-flow-pump.txt`

First line = title.
Remaining lines = description.

After pushing to `main`, GitHub Actions rebuilds `videos/manifest.json`, and the simulation automatically appears in the portfolio's CFD Simulation Library.
